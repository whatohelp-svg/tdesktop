# RiseGram Windows native port

Experimental source branch, not an installer. Uses the same single DC2 TCP endpoint and public RSA key as the Android client. Public Telegram fallback discovery and server-driven route replacement are disabled. A clean, separate app identity and local data directory, native builds, actual login/relaunch, chat/media and economy verification remain required before release. Do not distribute untested builds or reuse a Telegram data directory. Upstream license and source obligations remain in force.
